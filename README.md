# Browser Extensions Manager

A responsive browser extension management interface built with HTML, CSS and JavaScript.

## Features

- Display extensions from local JSON data
- Activate and deactivate extensions
- Filter extensions by status
- Remove extensions
- Switch between themes
- Responsive mobile and desktop layouts
- Interactive hover and focus states

## Tech Stack

- HTML5
- CSS3
- JavaScript
- JSON

## What I Practiced

This project improved my understanding of dynamic rendering, event handling, filtering data, managing UI state and creating responsive interactive interfaces.

## Run Locally

1. Clone the repository.
2. Open the project in VS Code.
3. Start it with a local development server.
4. Open the local URL in your browser.
